# dk-dsh-context-tree

按条回退对话：在 DeepSeek Harness 里点某条用户消息旁的图标，确认后会话就退回到那条消息之前，原文本回到输入框，改完直接发。如果这段对话改动过文件，弹窗还会列出能识别的改动；只有能证明安全的文件操作才可选，默认不会动文件。

回退**留在原对话**，不会新建会话。模型看不到所选消息及其后被撤回的内容，屏幕上的对应消息也会收起。插件只追加一条固定说明 `Conversation rewound.`（对话已回撤）；模型在下次请求时能看到这句说明，但说明不含撤回原文，回撤本身也不会发起模型请求。原始日志仍保留。

## 用法

1. 悬停在要重写的那一轮起始用户消息上，在时间与复制按钮那一行最右侧点回退图标。
2. 在弹窗里核对消息和文件清单，可逐个查看差异。已有文件只展示改动和跳过原因；如果有证据完整、可安全删除的新建文件，可以手动勾选文件选项。
3. 如果预览后会话又有新消息，或勾选的文件计划已经变化，必须重新打开预览并确认；不会扩大本次操作的范围。确认成功后，该消息及其之后的内容从对话里收起。
4. 这条消息的原文出现在输入框里。
5. 改完发送，对话从这条消息处继续。

刷新页面、重新打开会话、换一个窗口，收起状态都会从日志重建，不会重新冒出旧内容。

## 行为与边界

- 只撤回所选消息及其后仍在模型上下文里的部分。比如回撤 B 后发送 C、D，再回撤 D，会保留 C 和它的回复。原文仅作为输入草稿；再次发送前，模型看不到它。
- 文件处理不是工作区快照。插件只识别原生 `write` / `edit` 写进本次回撤范围的成功工具结果；`bash`、PTC 子调用、MCP 和其他会话等外部改动不在覆盖范围内。
- 当前 DSH 的文件差异是展示用文本，不能证明覆盖/编辑前的完整字节（例如末尾换行、原二进制内容）。**已有文件缺少可靠原文时只提示并跳过**，不会猜测还原成功。对本次范围内新建的文件，只有能从工具参数确认创建内容及后续变化，且文件当前整文一致，才允许按版本删除。
- 存在冲突、证据不足、只读、超出工作区、文件超过 2 MiB、后端缺少安全删除能力时，不执行对应文件操作。确认后文件又被编辑，版本检查也会阻止覆盖或删除。
- 必须先确认会话历史保存成功，才处理文件。若保存失败，内存中的对话可能已经回撤，但文件不会动；不要自动重试。会话保存成功后的个别文件失败单独报告。
- 插件不改写旧日志。升级前由旧版本已写入的回撤标记和已撤掉的轮次不自动修补；上述精确边界适用于新操作。
- goal、todo 等领域状态不会跟着回退。DSH 的消息遮蔽语义就是只改模型读到的内容。
- 只收起本插件执行的回退；DSH 自己的系统消息替换、上下文压缩（`compact-checkpoint`）和重放 `tool/result` 不会被误判成回退。
- 遮罩按会话隔离：切换会话时清空，不会把上一个会话的 turn 号或消息 id 带到新会话。
- 正在生成回复时拒绝回退（`session-busy`），避免和进行中的请求抢同一个 surface。
- 会话必须由当前 Host 持有（`session-not-active` 会直接提示）。冷会话不自动改成分支。
- 回退本身没有「撤销」按钮。它只恢复文字草稿，不恢复附件；缺少可信轮次或步骤信息、或目标不是该轮第一条聊天消息时，会拒绝回退，避免误收起同轮中仍应保留的内容。

## 安装

```bash
# 在 DSH 里安装本地 bundle
plugin_manager install_bundle target=file:/path/to/dk-dsh-context-tree
```

安装后刷新页面生效。Host 侧改动需要重载插件（禁用再启用）。

## 结构

| 文件 | 作用 |
| --- | --- |
| `index.js` | Host 半边：`preview`（预读这条消息之后的文件改动）、`truncate`（执行原地回退，可选还原文件）与 `cut`（只读查询已有回退范围）三条同源 JSON 路由 |
| `client.js` | Client 半边：消息行图标、遮罩、`cut` 重建；`createRowMask` 在 `dc:mask:*` 标记之间，测试逐字加载 |
| `src/plan.js` | 纯函数：定位消息、判断进行中的轮次、折叠回退范围、构造回退消息 |
| `src/files.js` | 纯函数：从日志收集文件改动、按文件分组、核对可逆证据、规划删除或跳过 |
| `test/` | `node:test` 单测：规划器、路由、遮罩工厂 |

## 开发

```bash
npm run check   # 语法检查 + 单元与路由测试
# 在 DSH 桌面运行时内加跑真实 Session、本地文件及 V4 日志落盘后冷读的隔离回归：
ELECTRON_RUN_AS_NODE=1 "$DSH_NODE_EXECUTABLE" --test test/session-rewind.test.js
```

没有构建步骤：`client.js` 由模块加载器按普通脚本读取，只允许 `require('react')`。
